# 铁锈战争模组开发 Agent 指南（分册索引）

> 面向 AI Agent 的《铁锈战争》(Rusted Warfare) 模组开发通用参考。涵盖工程结构与继承、单位/建筑/武器定义、luke 语运行时逻辑、非战斗/UI 模组技法、双语与元数据、进阶技法、验证与排坑。
>
> 本指南力求通用：不绑定任何具体工程，所有结论都基于《铁锈战争》引擎与 luke 语的真实行为。

## 适用对象

- **写给谁**：在任意 RW 模组里动手的 AI Agent（以及模组作者本人）。
- **怎么读**：第 0 章定角色与准则；第 1–3 章是地基（结构 / 定义 / 逻辑），必读；第 4 章做非战斗 / UI 模组时读；第 5 章碰文案 / 元数据时读；第 6 章要炫技时翻；第 7 章动手前后对照自检；第 8 章是速查。

## 一条总铁律

**先查，再写；查代码表 / 维基 / 真实文件，不要凭记忆。** 动手前先打开最近邻的真实节，照抄它的节名、键名、大小写、缩进，再改。luke 语节名 / 键名**区分大小写**，拼错不报错、只会静默失效。注释、他人指南乃至本参考都可能滞后于引擎版本。
