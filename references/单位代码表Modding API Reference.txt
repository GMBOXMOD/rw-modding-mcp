单位代码
总说明：[section] 节，name:value 键/代码：值，参数。便于习惯，一般称为代码而不是键。翻译一般为键。在铁锈战争游戏中也可用使用=，但不是所有:都可以用=代替。建议根据例子使用。注意代码中除了注释和描述文本，所有符号都为英文符号。许多布尔值的true和false可以写成1或0，但不建议这么做。

A：核心[core]
A-a：通用代码、A-b：单位统计代码、A-c：UI和图形代码、A-d：仅构建代码、A-e：杂项代码、A-f：运输代码、A-g：资源节点代码、A-h：资源收集器代码、A-i：建筑和工厂代码、A-j：死亡代码、A-k：动作代码、A-l：不建议使用的代码

A-a：通用代码
分类说明：多是必要的代码，如果不包括这些，可能导致错误

A-a-1：name（名字）
描述：定义单位原始名称，可以是中文。游戏使用它区分其它单位。如果没有在displayText或者语言文件设置显示名称，那么它也将作为单位的显示名称。；具体描述文件位置:assets/translationsStrings_zh.properties格式:units.单位名称.name=写单位显示的名称；units.单位名称.description= [[填单位显示的描述]]
约束：名称不能是 self；名称不能以 self. 开头
正确例子：name:customTank1；name:自定义坦克；name:shibainu
错误例子：name:self；name:self.name
值类型：string

A-a-2：altNames（别名）
描述：以逗号分隔的名称列表。像名称一样，但优先级较低，对于启用多个自定义mod有用。
正确例子：altNames:custTank1,customTank1,cTank1
值类型：string(s)

A-a-3：class（类）
描述：无实际用处，可以删除。Luke说：保留供将来使用，默认情况下最好为CustomUnitMetadata。
正确例子：class: CustomUnitMetadata
值类型：string

A-a-4：strictLevel（严格级别）
描述：默认值为0，忽略代码重复。设为1时如果当前单位内有重复代码，则报错。建议添加到"all-units.template"以应用于所有单位,进行统一查错。
正确例子：strictLevel:1
值类型：integer

A-a-5：price（价格）
描述：设定单位造价，可以是负数，负数时直接提供资金。
正确例子：price: 500
值类型：price(s)

A-a-6：mass（质量）
描述：单位的“重量”定义了它与其他单位的碰撞方式，值越大，推动就越困难。
正确例子：mass: 3000
值类型：integer

A-a-7：techLevel（科技等级）
描述：设置单位的科技等级，共有3个级别，1级GUI显示为绿色，2、3级显示为黄色。
正确例子：techLevel: 1
值类型：integer

A-a-8：buildSpeed（建造速度）
描述：建造此单位需要的时间，填秒。以前的计算方式为：此处所填时间=1÷(60x您需要的秒)如果定义了工厂速率则需要乘以建造乘数。
正确例子：buildSpeed: 3s
值类型：time

A-a-9：radius（半径）
描述：单位的实际碰擦体积，也是实际的可选择范围。其光圈在displayRadius覆盖时真实体积不变。
正确例子：radius: 20
值类型：integer

A-a-10：isBio（是生物）
描述：此单位是否为生物，为生物则影响死亡声音和血迹（图像在drawable/blood_mark.png，hideScorchMark：true时可以隐藏）非生物则为黑色爆炸效果。
正确例子：isBio: true
值类型：boolean

A-a-11：isBug（是虫子）
描述：是否为虫子，用于沙盒中的单独分类。
正确例子：isBug: false
值类型：boolean

A-a-12：isBuilder（是建造者）
描述：若需要此单位建造建筑物，则通常需要此代码。并且默认设为[ai] useAsBuilder。
正确例子：isBuilder: true
值类型：boolean

A-a-13：streamingCost（流式造价）
描述：就像价格，但在建造时逐渐消耗资金，如果在构建过程中资源耗尽，建造或生产队列将暂停。就像是红警中那样。铁锈默认是预先扣除资金。
正确例子：streamingCost:100
值类型：price(s)

A-a-14：switchPriceWithStreamingCost（切换价格为流式造价）
描述：快捷设置为默认资金消耗方式或为流式建造方式。建议使用模板快速将一个模组为所有单位切换流资源。
正确例子：switchPriceWithStreamingCost:true
值类型：boolean

A-b：单位统计代码

A-b-1：maxHp（生命值）
描述：单位最大生命值，默认生成时即为此值。
正确例子：maxHp: 200
值类型：integer

A-b-2：selfRegenRate（生命恢复速度）
描述：此数值决定每帧增加血量。游戏内默认速度下，一秒为60逻辑帧，而您看到的FPS帧数为渲染帧，所以电脑上几百帧和手机上60帧和省电模式下30帧并不影响计算。所以不要写太大。可以写负值用于自毁。
正确例子：selfRegenRate: 0.01
值类型：float

A-b-3：maxShield（护盾值）
描述：单位最大护盾值，默认生成时即为此值。如果设置了startShieldAtZero:true，则初始为0.
正确例子：maxShield: 500
值类型：integer

A-b-4：startShieldAtZero（护盾初始为0）
描述：如果为true，则单位护盾值从0开始增加。
正确例子：startShieldAtZero: true
值类型：boolean

A-b-5：shieldRegen（护盾恢复速度）
描述：此数值决定每帧增加护盾值，游戏内一秒为60帧，所以不要写太大。可以写负值。（默认值为0.25）
正确例子：shieldRegen: 0.15
值类型：float

A-b-6：energyMax（能量值）
描述：默认值为0。可以用作炮塔，激光防御和行动的弹药的能量。
正确例子：energyMax: 1
值类型：float

A-b-7：startEnergyAtZero（能量初始为0）
描述：如果为true，则单位能量值从0开始增加。
正确例子：startEnergyAtZero: true
值类型：boolean

A-b-8：energyRegen（能量恢复速度）
描述：能量每帧恢复速度，游戏内一秒为60帧，所以不要写太大。可以写负值。
正确例子：energyRegen: 0.01
值类型：float

A-b-9：energyRegenWhenRecharging（充能时能量恢复速度）
描述：能量恢复是持续的，如果您设置了energyNeedsToRechargeToFull，那么攻击时按energyRegen恢复，耗尽时的灰条按此处设定值恢复。
正确例子：energyRegenWhenRecharging:0.1
值类型：float

A-b-10：energyStartingPercentage（能量初始百分比）
描述：单位生成时所携带的能量百分比。
正确例子：energyStartingPercentage: 0.5
值类型：float

A-b-11：energyNeedsToRechargeToFull（能量需要充满）
描述：若果能量耗尽，则需要完全充能才能进行攻击。
正确例子：energyNeedsToRechargeToFull: true
值类型：boolean

A-b-12：energyDisplayName（能量显示名称）
描述：能量显示名称,目前似乎无效.1.15
正确例子：energyDisplayName:chemms
值类型：string

A-b-13：armour（装甲）
描述：抵消敌方攻击所造成的伤害。
正确例子：armour: 6
值类型：float

A-b-14：armourMinDamageToKeep（装甲最低伤害）
描述：至少造成多少点伤害，默认为1.防止护甲太高完全打不动。
正确例子：armourMinDamageToKeep: 2
值类型：float

A-b-15：borrowResourcesWhileAlive（资源活着时借用）
描述：创建时获取这些资源，删除或销毁时将其返回。例如用于电力逻辑，负数供电和正数耗电。
正确例子：borrowResourcesWhileAlive: gold=10
值类型：price(s)

A-b-16：borrowResourcesWhileBuilt（资源在单位建成后借用）
描述：类似于[core]borrowResourcesWhileAlive但在单位建成后才会生效。主要对房屋之类的建筑有用，这些建筑有负的资源，可以加到单位上限等
正确例子：borrowResourcesWhileBuilt:gold=100
值类型：price(s)

A-b-17：generation_resources（资源获取）
描述：单位定时获得的资源，可自定义资源。
正确例子：generation_resources: credits=5, gold=20
值类型：price(s)

A-b-18：generation_active（资源取得条件）
描述：获取资源条件。可用于受损时无法产出。
正确例子：generation_active: if not self.hp(lessThan=100)
值类型：logicbooleanean

A-b-19：generation_credits（资金获取）
描述：生成资源，仅用于默认的资金，也就是铁锈默认的金钱。
正确例子：generation_credits: 2
值类型：integer

A-b-20：generation_delay（资金获取时间）
描述：多久帧添加一次资源（generation_credits 指定数值）。默认值为40；游戏逻辑帧率按60帧/秒计算，因此默认约为0.67秒。Luke不建议使用。
正确例子：generation_delay: 40
值类型：integer

A-d：仅构建代码

A-d-1：isBuilding（是建筑）
描述：定义单位是否为建筑物。
正确例子：isBuilding: true
值类型：boolean

A-d-2：footprint（建筑碰撞范围）
描述：填四个数值(左，上，右，下)，单位是格子，建筑默认占一格，向左和向上需要填负数，填整数在选择时有偏移。；四个数值可以完全颠倒，这样不会阻碍单位移动。；决定建筑单位碰撞体积，此区域内单位不能通过，如果在单位运动途中单位则会绕过。单位实际可选择面积使用的是radius。
正确例子：（1x1）footprint: 0,0,0,0；（2X2）footprint: 0,0,1,1；（3X3）footprint: -1,-1,1,1
值类型：integers

A-d-3：constructionFootprint（建筑覆盖范围）
描述：基础规则同上，这个区域内不能建造建筑，但是单位可以通过。一般需要设定比上一个面积大。好处是即使建造的密密麻麻，单位也有路可走
正确例子：constructionFootprint: -1,-1,1,3
值类型：integers

A-d-4：displayFootprint（建筑选择UI）
描述：基础规则同上，用于选择单位时UI显示。不设定则默认为建筑覆盖区域。
正确例子：displayFootprint: 0,0,1,1
值类型：integers

A-d-5：buildingSelectionOffset（建筑UI调整）
描述：默认值为0。以像素为单位对选框额外设定。
正确例子：buildingSelectionOffset: 4
值类型：integer

A-d-6：buildingToFootprintOffsetX（建筑X轴偏移）
描述：设置X轴位置偏移，默认10.若设置非对称的建筑，单位会根据覆盖范围会挤在角上，这时如果要准确显示就需要额外偏移。与直接使用图像偏移的区别:；由于铁锈判断选中单位是根据单位体积(radius),因此图像偏移实际上单位的位置不变，会容易造成点击时的误差。而当前代码实际上是移动单位，则不会造成这个问题。
正确例子：buildingToFootprintOffsetX: 4
值类型：float

A-d-7：buildingToFootprintOffsetY（建筑Y轴偏移）
描述：设置Y轴位置偏移，默认10.其它参上条
正确例子：buildingToFootprintOffsetY: 6
值类型：float

A-d-8：placeOnlyOnResPool（建筑只能建造在资源池上）
描述：通常用于提取器，会强制在资源池中进行建筑物构造。可以用于在自定义战役中限制某单位只能在某地建造。
正确例子：placeOnlyOnResPool: true
值类型：boolean

A-d-9：selfBuildRate（自动建造速度）
描述：此单位自动构造所需要的时间，目前用于虫族。计算方式为：此处所填时间=1÷(60x您需要的秒)。
正确例子：selfBuildRate: 0.0008
值类型：float

A-d-10：ignoreInUnitCapCalculation（不计入单位数量统计）
描述：铁锈中有单位数量上限设定，填true时不计入统计，多用于辅助单位，建筑物的默认值为true。
正确例子：ignoreInUnitCapCalculation:true
值类型：boolean

R：模板[template_NAME]

R-1：@copyFromSection（复制节）
描述：模板部分可以具有任何键，并且其自身无效。；可以使用[core]copyFrom从其他文件中引用模板。例如：[core]copyFrom:ROOT:effects/explodeEffects.template。copyFrom可以一次引用多个文件。；-以下所有这些功能都可以与任何部分一起使用，而不仅仅是模板-；在任何节中使用，以引用节或模板的代码。如@copyFromSection template_name/action_name/projectile_name
正确例子：@copyFromSection:projectile_1

R-2：@copyFrom_skipThisSection（复制但跳过节）
描述：在任何节中使用，例如，在引用时候不复制某个action.
正确例子：[action_test]；@copyFrom_skipThisSection:true

R-3：@define X（局部变量）
描述：在一个节中定义一个局部变量(最好在模板外部)
约束：禁止变量套娃引用；变量名称禁止包含字符：=，}，$，.，{，-，+，:，(；变量名称禁止以数字开头
正确例子：@define targetEffect: boom
错误例子：@define a:${b}

R-4：@global X（全局变量）
描述：定义在所有节中使用的全局变量。注意：局部变量具有更高的优先级
约束：禁止变量套娃引用；变量名称禁止包含字符：=，}，$，.，{，-，+，:，(；变量名称禁止以数字开头
正确例子：@global targetEffect: pop
错误例子：@global a:${b}

R-5：${X}（变量引用）
描述：该方法用于引用section中@define或者@global定义的变量的值，可以作为代码插入使用，运算符和数学方法的使用请在代码表logic区中背景颜色为肉色或紫色处查看
约束：它是唯二支持 ^ 运算符的区域；在代码里有引用上限
正确例子：spawnEffects:effect_${targetEffect}

R-6：${section.key}（值引用）
描述：该方法用于引用指定section下的key所填的值，可以作为代码插入使用，运算符和数学方法的使用请在代码表logic区中背景颜色为肉色或紫色处查看，冷知识请跳转“其他”工作簿第二栏目底部寻找
约束：它是唯二支持 ^ 运算符的区域；在代码里有引用上限
正确例子：addResources:credits=${core.price * 2 + 10}

R-7：%{X}（%{X}）
描述：可用于将动态逻辑添加到某些字符串中（此方式只能用于字符串(mod-info.txt的除外)）。 该值将每一帧更新。；[action]text: Missing hp %{self.maxHp - self.hp}

R-8："""[文本]"""（多行代码；多行注释）
描述：可用于多行字符填写。 从最终结果中删除换行符。ini文件任意地方均可使用。但需注意，您在打了一个"""后，必须要有一个"""与之对应，否则一定报错，不能用'''，否则也报错；"""在位于最行首时，作用将会改为多行注释
约束：三引号必须成对闭合；不能使用 ''' 代替 """
正确例子：copyFrom:"""；ROOT:a.ini,；ROOT:b.ini,；ROOT:c.ini；"""；"""；这是一个多行注释；233；233；233；233；"""（这里也可以是一个注释）
错误例子：copyFrom:"""（未闭合）；copyFrom:'''ROOT:a.ini'''

R-9：IGNORE（忽略（必须大写））
描述：一个特殊的值，所有代码均可填写，填写后什么都不会发生，一般用于section之间的复制，即忽略该代码的复制
正确例子：[hiddenAction_ok]；spawnUnits:IGNORE；requireConditional:IGNORE；autoTrigger:IGNORE
